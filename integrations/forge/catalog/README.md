# Curriculum registrations

Each entry identifies a canonical teaching source, its publication disposition,
builder, evidence getter and result category. The generated inventory also shows
unregistered entrypoints as pending. Registering an entry does not claim it has
been published or validated.

## Volume I

All 17 Co-Labs retain their original controls, scenario tracks, comparison
snapshots and Design Ledger export. Orientation is a supplied interface rehearsal;
the remaining lessons are analytical simulations. The Forge panel publishes a
snapshot only after an explicit click, with disabled mode as the default.
Student predictions and reflections remain local unless explicitly selected for
a separate sharing workflow; the integration never treats a prediction as a
measured result. Use `python -m mlsysbook_forge build --lab-id LAB_ID` to prepare
a standalone copy, and follow [publication checks](../NOTEBOOKS.md).
